    1.1Repaso express de listas8 min

    Lo que necesitamos de la clase anterior

    Indexación

    Desde 0 hasta len - 1; -1 es el último.

    Mutabilidad

    Se cambian “en el lugar”: t[i] = valor.

    Métodos

    append, insert, remove, pop, sort, copy.

    Referencias

    b = a no copia: ambas apuntan a la misma lista.

    Las cuatro ideas reaparecen multiplicadas en las matrices: cada fila es una lista con todas estas propiedades.

    Alerta de error típico: reasignar un método in-place

    t = t.append(x) deja t valiendo None. Con matrices es peor: fila = fila.sort() no rompe en esa línea, sino varias líneas después. Los métodos que modifican la lista devuelven None.

    t = [30, 10, 20]
print(t[0], t[-1])     # 30 20 -> primer y último elemento
t[1] = 15              # mutabilidad: cambio en el lugar
t.append(40)           # agrega al final (devuelve None)
t.insert(0, 5)         # inserta en la posición 0
quitado = t.pop()      # quita y DEVUELVE el último
print(t, quitado)      # [5, 30, 15, 20] 40

b = t                  # alias: misma lista
c = t.copy()           # copia: lista nueva
b.append(99)
print(t)               # [5, 30, 15, 20, 99] <- cambió por b
print(c)               # [5, 30, 15, 20]     <- la copia no

    1.2La matriz como lista de listas10 min

    Filas, columnas y dimensiones

    Una matriz es una lista cuyos elementos son listas del mismo largo. Cada sublista es una fila; la posición dentro de la fila es la columna.

    Filas

    len(matriz): cuántas sublistas hay.

    Columnas

    len(matriz[0]): cuánto mide una fila.

    Explorador: tocá una celda para ver cómo se accede. Usá los botones para resaltar su fila, su columna o la diagonal.

    Nota para el docente

    Insistí con la frase “primero la fila, después la columna”. Con el explorador, pedí a alguien que diga en voz alta cómo accedería al 10 antes de tocarlo. Remarcá que la matriz del ejemplo es de 3x4: no es cuadrada, y eso importa en el Módulo 3.

    matriz = [
    [1, 2, 3, 4],       # fila 0
    [5, 6, 7, 8],       # fila 1
    [9, 10, 11, 12],    # fila 2
]

filas = len(matriz)           # 3 -> cantidad de sublistas
columnas = len(matriz[0])     # 4 -> largo de una fila
print(f"Dimensión: {filas}x{columnas}")

print(matriz[0])              # [1, 2, 3, 4] -> una fila completa
print(matriz[2][1])           # 10 -> fila 2, columna 1
print(matriz[-1][-1])         # 12 -> última fila, última columna

# Una COLUMNA no se obtiene directo: hay que recorrer las filas
columna_1 = []
for fila in matriz:
    columna_1.append(fila[1])
print(columna_1)              # [2, 6, 10]
    Alerta de error típico: sintaxis de NumPy en listas nativas

    Dos confusiones muy frecuentes de quien vio NumPy o leyó código de ciencia de datos:

    • matriz[1, 2] → TypeError: en listas nativas la coma arma una tupla. Lo correcto es matriz[1][2].
    • matriz[:][1] no devuelve la columna 1: matriz[:] es una copia de la matriz entera, y [1] toma su fila 1.
    matriz = [[1, 2, 3], [4, 5, 6]]
print(matriz[:][1])    # [4, 5, 6] -> ¡es la FILA 1, no la columna!
print(matriz[1, 2])    # TypeError: list indices must be integers or slices, not tuple

    1.3Modificar y hacer crecer una matriz5 min

    Cambiar celdas, filas y dimensiones

    Como cada fila es una lista mutable, se puede cambiar una celda (m[i][j] = v), una fila entera (m[i] = [...]) o agregar filas con append(). Para agregar una columna hay que hacer append() en cada fila.

    Alerta de error típico: filas de distinto largo (matriz “dentada”)

    Python permite [[1, 2, 3], [4, 5]], pero ya no es una matriz rectangular. Cualquier recorrido que use len(m[0]) como cantidad de columnas va a fallar con IndexError en la fila corta. Al agregar una columna, no te olvides de ninguna fila.

    m = [
    [0, 0, 0],
    [0, 0, 0],
]
m[0][2] = 7             # modificar UNA celda: fila 0, columna 2
m[1] = [4, 5, 6]        # reemplazar una FILA entera
m.append([8, 8, 8])     # agregar una fila nueva al final
for fila in m:          # agregar una COLUMNA: un valor por fila
    fila.append(1)

for fila in m:
    print(fila)
print(f"Ahora es de {len(m)}x{len(m[0])}")   # 3x4

    1.4Mutabilidad y aliasing en matrices12 min

    El error más grave: [[0] * 3] * 3

    [0] * 3 crea una fila. Al multiplicar por 3 la lista exterior, Python no crea tres filas: repite tres veces la referencia a la misma fila. Cambiar una celda “cambia” toda la columna.

    ¿Por qué [0] * 3 sí funciona para la fila? Porque los int son inmutables: compartir el 0 no es un problema. Las listas, en cambio, son mutables.

    Simulador: elegí cómo se crea M y ejecutá la asignación.

    Alerta de error típico: copiar una matriz con .copy()

    M.copy() o M[:] copian la lista exterior, pero las filas siguen compartidas. Para una copia independiente: [fila.copy() for fila in M] o copy.deepcopy(M).

    import copy

M = [[1, 2], [3, 4]]
superficial = M.copy()
superficial[0][0] = 99
print(M)                         # [[99, 2], [3, 4]] <- ¡cambió la original!

M = [[1, 2], [3, 4]]
independiente = [fila.copy() for fila in M]   # copia fila por fila
profunda = copy.deepcopy(M)                   # alternativa del módulo copy
independiente[0][0] = 99
profunda[1][1] = 77
print(M)                         # [[1, 2], [3, 4]] <- intacta
    # ERROR: las 3 filas son la MISMA lista
M = [[0] * 3] * 3
M[0][0] = 5
print(M)                  # [[5, 0, 0], [5, 0, 0], [5, 0, 0]]
print(M[0] is M[1])       # True -> misma fila en memoria

# CORRECTO 1: bucle que crea una fila NUEVA en cada vuelta
M = []
for i in range(3):
    M.append([0] * 3)     # [0] * 3 se evalúa 3 veces -> 3 filas distintas
M[0][0] = 5
print(M)                  # [[5, 0, 0], [0, 0, 0], [0, 0, 0]]

# CORRECTO 2: comprensión de listas (lo mismo, en una línea)
M = [[0] * 3 for _ in range(3)]
M[0][0] = 5
print(M)                  # [[5, 0, 0], [0, 0, 0], [0, 0, 0]]
print(M[0] is M[1])       # False -> filas independientes
    # El aliasing también aparece al "guardar" una fila en otra variable
M = [[1, 2, 3], [4, 5, 6]]
primera = M[0]            # NO es copia: es la misma fila
primera[0] = 100
print(M)                  # [[100, 2, 3], [4, 5, 6]]

# Si querés trabajar aparte, copiá la fila
primera = M[0].copy()
primera[0] = -1
print(M[0])               # [100, 2, 3] <- no cambió
    Nota para el docente

    Antes de ejecutar el primer bloque, hacé una votación a mano alzada: “¿cuántos 5 va a haber?”. La mayoría responde uno. Dibujá tres flechas desde M hacia una sola caja. Este error aparece en exámenes y también en código profesional.

    2.1Recorrido por índices8 min

    Dos bucles, dos índices

    El bucle externo recorre las filas (i) y el interno las columnas (j). Por cada vuelta del externo, el interno se ejecuta completo: en una matriz de 3x4 el cuerpo se ejecuta 12 veces.

    Usá len(m) para las filas y len(m[i]) (o len(m[0]) si es rectangular) para las columnas.

    Nota para el docente

    Ejecutá el primer bloque y pedí que observen el orden en que aparecen las coordenadas: fila por fila. Después preguntá: “¿Qué cambia si intercambio los dos for?”. Es la base de la suma por columnas.

    m = [
    [1, 2, 3],
    [4, 5, 6],
]
for i in range(len(m)):              # i recorre las filas: 0, 1
    for j in range(len(m[i])):       # j recorre las columnas: 0, 1, 2
        print(f"m[{i}][{j}] = {m[i][j]}")

# Con índices SÍ podemos modificar la matriz
for i in range(len(m)):
    for j in range(len(m[i])):
        m[i][j] = m[i][j] * 10
print(m)                             # [[10, 20, 30], [40, 50, 60]]

    2.2Recorrido por elementos7 min

    Más simple, pero sin posiciones

    for fila in matriz entrega cada sublista; for x in fila entrega cada valor. Es ideal para imprimir, sumar o contar. Si además necesitás la posición, enumerate() te da índice y elemento a la vez.

    Alerta de error típico: modificar la variable del bucle

    En for x in fila: x = 0, x es una variable suelta que recibe una copia del valor (un número inmutable). Reasignarla no cambia la matriz. Para modificar, usá índices: fila[j] = 0.

    m = [
    [1, 2, 3],
    [4, 5, 6],
]
for fila in m:                 # fila = [1, 2, 3], luego [4, 5, 6]
    for x in fila:             # x = cada número de la fila
        print(x, end=" ")
    print()                    # salto de línea al terminar la fila

# Trampa: esto NO modifica la matriz
for fila in m:
    for x in fila:
        x = 0
print(m)                       # [[1, 2, 3], [4, 5, 6]] <- intacta

# enumerate: elementos + posición, sin range(len(...))
for i, fila in enumerate(m):
    for j, x in enumerate(fila):
        if x % 2 == 0:
            fila[j] = 0        # modificar SÍ funciona, por índice
print(m)                       # [[1, 0, 3], [0, 5, 0]]

    2.3Operaciones nativas: sumas y diagonal12 min

    Cuatro cálculos, un mismo esqueleto

    Suma total

    Un acumulador fuera de los dos bucles.

    Por filas

    Acumulador que se reinicia dentro del bucle de filas.

    Por columnas

    Bucles invertidos: afuera j, adentro i.

    Diagonal principal

    Las celdas donde i == j. Solo en matrices cuadradas.

    Las resolvemos con bucles para entender el mecanismo. sum(fila) es una función nativa válida que podés usar como atajo una vez que entendés qué hace.

    Alerta de error típico: el acumulador en el lugar equivocado

    Si suma_fila = 0 queda fuera del bucle de filas, cada fila arrastra la suma de las anteriores: obtenés sumas acumuladas en vez de sumas por fila. Si queda dentro del bucle interno, se reinicia en cada celda y siempre vale el último número.

    Alerta de error típico: diagonal con un solo bucle mal armado

    Para la diagonal no hacen falta dos bucles: m[i][i] con un solo for i in range(len(m)) alcanza. Si la matriz no es cuadrada, validá antes (len(m) == len(m[0])); si no, aparece un IndexError o una “diagonal” incompleta.

    m = [
    [2, 4, 6],
    [1, 3, 5],
    [7, 8, 9],
]
n = len(m)

# 1) Suma total
total = 0
for fila in m:
    for x in fila:
        total += x
print("Total:", total)                    # 45

# 2) Suma por filas
sumas_filas = []
for fila in m:
    suma_fila = 0                         # se reinicia en CADA fila
    for x in fila:
        suma_fila += x
    sumas_filas.append(suma_fila)
print("Por filas:", sumas_filas)          # [12, 9, 24]

# 3) Suma por columnas: bucles invertidos
sumas_cols = []
for j in range(len(m[0])):                # afuera: columnas
    suma_col = 0
    for i in range(len(m)):               # adentro: filas
        suma_col += m[i][j]
    sumas_cols.append(suma_col)
print("Por columnas:", sumas_cols)        # [10, 15, 20]

# 4) Diagonal principal: i == j
diagonal = 0
for i in range(n):
    for j in range(n):
        if i == j:
            diagonal += m[i][j]
print("Diagonal (doble bucle):", diagonal)   # 14

diagonal = 0
for i in range(n):                        # versión directa: m[i][i]
    diagonal += m[i][i]
print("Diagonal (un bucle):", diagonal)      # 14

# Bonus: diagonal secundaria -> i + j == n - 1
secundaria = 0
for i in range(n):
    secundaria += m[i][n - 1 - i]
print("Diagonal secundaria:", secundaria)    # 16

    2.4Máximo y mínimo con sus coordenadas8 min

    Recordar el valor y dónde está

    Además del valor, guardamos fila y columna del mejor encontrado. Por eso conviene recorrer por índices. Los extremos se inicializan con una celda real, m[0][0], nunca con 0.

    Alerta de error típico: inicializar el máximo con 0

    Con una matriz de temperaturas bajo cero, maximo = 0 devuelve 0, un valor que ni siquiera está en la matriz, y coordenadas inventadas. Inicializá con m[0][0] y coordenadas (0, 0).

    Y ojo con los empates: > se queda con la primera aparición; >=, con la última.

    m = [
    [3, 8, 1],
    [9, 2, 7],
    [4, 6, 5],
]

maximo, fila_max, col_max = m[0][0], 0, 0     # arrancar con una celda REAL
minimo, fila_min, col_min = m[0][0], 0, 0

for i in range(len(m)):
    for j in range(len(m[i])):
        if m[i][j] > maximo:
            maximo, fila_max, col_max = m[i][j], i, j
        if m[i][j] < minimo:
            minimo, fila_min, col_min = m[i][j], i, j

print(f"Máximo: {maximo} en (fila {fila_max}, columna {col_max})")   # 9 en (1, 0)
print(f"Mínimo: {minimo} en (fila {fila_min}, columna {col_min})")   # 1 en (0, 2)

    3.2Detectar aliasing entre filas6 min

    Las filas tienen “huella digital”

    Si al modificar una celda cambian varias filas, sospechá aliasing. Dos herramientas nativas para confirmarlo:

    • m[0] is m[1]: True si son el mismo objeto.
    • id(fila): si dos filas tienen el mismo id, son la misma lista.

    Con una función de diagnóstico podés revisar cualquier matriz antes de usarla.

    Alerta de error típico: agregar la misma fila varias veces

    Crear fila = [0, 0, 0] fuera del bucle y hacer m.append(fila) adentro produce el mismo problema que [[0] * 3] * 3. La fila nueva tiene que crearse dentro del bucle.

    def filas_compartidas(m):
    """Devuelve los pares de filas que son el MISMO objeto."""
    pares = []
    for i in range(len(m)):
        for j in range(i + 1, len(m)):
            if m[i] is m[j]:
                pares.append((i, j))
    return pares

# Bug sutil: la fila se crea UNA sola vez, fuera del bucle
fila = [0, 0, 0]
m = []
for _ in range(3):
    m.append(fila)
for f in m:
    print("[DEBUG] id de la fila:", id(f))
print("Filas compartidas:", filas_compartidas(m))   # [(0, 1), (0, 2), (1, 2)]

# Corrección: crear la fila DENTRO del bucle
m = []
for _ in range(3):
    m.append([0, 0, 0])
print("Filas compartidas:", filas_compartidas(m))   # []

    3.3Patrón guardián para matrices vacías6 min

    Validar antes de recorrer

    Una matriz puede llegar vacía de dos formas: [] (sin filas) o [[]] (una fila sin columnas). En ambos casos m[0][0] rompe. El guardián se escribe al principio de la función y sale con return:

    Insuficienteif len(m) == 0:no detecta [[]]
    Completoif not m or not m[0]:detecta los dos casos

    El orden importa: not m va primero. Si m está vacía, Python ni siquiera evalúa m[0] (evaluación en cortocircuito).

    Nota para el docente

    Pedí que prueben maximo_matriz([]) sin el guardián para que vean el error real. Después agregan la línea y vuelven a probar. Conectá con el Módulo 4: todos los ejercicios clave empiezan con un guardián.

    def es_rectangular(m):
    """Guardianes: no vacía y todas las filas del mismo largo."""
    if not m or not m[0]:             # [] o [[]]
        return False
    columnas = len(m[0])
    for fila in m:
        if len(fila) != columnas:     # fila "dentada"
            return False
    return True

def maximo_matriz(m):
    if not es_rectangular(m):         # guardián: sale antes de fallar
        return None
    maximo = m[0][0]
    for fila in m:
        for x in fila:
            if x > maximo:
                maximo = x
    return maximo

print(maximo_matriz([[3, 9], [4, 1]]))   # 9
print(maximo_matriz([]))                 # None, en vez de IndexError
print(maximo_matriz([[]]))               # None
print(maximo_matriz([[1, 2], [3]]))      # None (no es rectangular)

     Ver pista
    Dentro de la función, un bucle de filas que en cada vuelta crea una fila nueva. Para la identidad: partí de una matriz de ceros y recorré con un solo bucle poniendo m[i][i] = 1.
    
  
     Ver solución explicada
    1. Guardián: si filas o columnas no son positivos, devolvé [].
    2. Bucle externo de filas: en cada vuelta creá fila = [] dentro del bucle.
    3. Bucle interno: fila.append(valor) tantas veces como columnas; al final m.append(fila).
    4. Identidad: crear_matriz(4, 4, 0) y luego for i in range(4): m[i][i] = 1.

    def crear_matriz(filas, columnas, valor):
    if filas <= 0 or columnas <= 0:       # guardián

    m = []
    for _ in range(filas):
        fila = []                         # fila NUEVA en cada vuelta
        for _ in range(columnas):
            fila.append(valor)
        m.append(fila)
    return m

    Suma de dos matrices
     Avanzado
    
  
    Escribí sumar_matrices(a, b) que devuelva una matriz nueva con la suma elemento a elemento. Si las dimensiones no coinciden (o alguna está vacía), devolvé None. Las matrices originales no deben modificarse.
    Salida esperada
    [[11, 22, 33], [44, 55, 66]]
None
[[1, 2, 3], [4, 5, 6]]
    
  
     Tu solución
    
  
    
  
     Ver pista
    La celda c[i][j] es a[i][j] + b[i][j]. Construí c fila por fila con append().
    
  
     Ver solución explicada
    1. Guardián 1: ninguna vacía (not a or not a[0], ídem b).
    2. Guardián 2: mismas filas (len(a) == len(b)) y mismas columnas (len(a[0]) == len(b[0])).
    3. Recorré por índices: para cada i, creá fila = [] y agregá a[i][j] + b[i][j] para cada j.
    4. Agregá la fila a c y devolvé c. Como es una matriz nueva, a y b quedan intactas.
    def sumar_matrices(a, b):
    if not a or not a[0] or not b or not b[0]:          # guardián 1
        return None
    if len(a) != len(b) or len(a[0]) != len(b[0]):      # guardián 2
        return None
    c = []
    for i in range(len(a)):
        fila = []
        for j in range(len(a[0])):
            fila.append(a[i][j] + b[i][j])
        c.append(fila)
    return c

    Matriz transpuesta
     Avanzado
    
  
    Calculá la transpuesta de una matriz: las filas pasan a ser columnas. Si la original es de 2x3, la transpuesta es de 3x2. Resolvelo con bucles y después con comprensión de listas.
    Salida esperada
    [[1, 4], [2, 5], [3, 6]]
2x3 -> 3x2
True
True
    
  
     Tu solución
    
  
    
  
     Ver pista
    La regla es t[j][i] = m[i][j]. Ojo: la transpuesta tiene len(m[0]) filas y len(m) columnas. Cada fila de la transpuesta es una columna de la original.
    
  
     Ver solución explicada
    1. Guardián para matriz vacía.
    2. El bucle externo recorre las columnas de m (j): cada una genera una fila de t.
    3. El bucle interno recorre las filas de m (i) y agrega m[i][j].
    4. Es el mismo recorrido que la suma por columnas, pero en vez de sumar, guarda los valores.
    5. Comprobación: transponer dos veces devuelve la matriz original.
    m = [
    [1, 2, 3],
    [4, 5, 6],
]

def transpuesta(m):
    if not m or not m[0]:                  # guardián
        return []
    t = []
    for j in range(len(m[0])):             # cada COLUMNA de m...
        nueva_fila = []
        for i in range(len(m)):            # ...recorrida de arriba a abajo
            nueva_fila.append(m[i][j])
        t.append(nueva_fila)               # ...es una FILA de t
    return t

t = transpuesta(m)
print(t)                                    # [[1, 4], [2, 5], [3, 6]]
print(f"{len(m)}x{len(m[0])} -> {len(t)}x{len(t[0])}")

# Misma idea con comprensión de listas
t2 = [[m[i][j] for i in range(len(m))] for j in range(len(m[0]))]
print(t2 == t)                              # True
print(transpuesta(t) == m)                  # True: ida y vuelta

    D1
    Detección del punto silla
     Nivel Dios
    
  
    Un punto silla es una celda que es el mínimo de su fila y, a la vez, el máximo de su columna. Escribí puntos_silla(m) que devuelva una lista con todos los puntos silla como (fila, columna, valor). Probala con las dos matrices: la primera tiene uno y la segunda ninguno.
    Salida esperada
    [DEBUG] min_filas: [1, 7, 2] max_cols: [11, 7, 10]
[(1, 1, 7)]
[DEBUG] min_filas: [1, 0] max_cols: [3, 2]
[]
    
  
     Tu solución
    
  
    
  
     Ver pista
    Dividí el problema: primero calculá una lista con el mínimo de cada fila y otra con el máximo de cada columna (como en el Módulo 2). Después, una celda es silla si m[i][j] == min_filas[i] and m[i][j] == max_cols[j].
    
  
     Ver solución explicada
    1. Guardián: matriz vacía → lista vacía.
    2. Paso 1: min_filas: para cada fila, el mínimo inicializado con su primer elemento.
    3. Paso 2: max_cols: bucles invertidos (afuera j), máximo inicializado con m[0][j].
    4. Paso 3: recorré por índices y quedate con las celdas que cumplen las dos condiciones.
    5. Precalcular las listas evita recalcular el mínimo de la fila en cada celda: es más eficiente y mucho más fácil de depurar.
    col 0col 1col 2min_filas
    fila 09181
    fila 1117107
    fila 24262
    max_cols11710→ silla en (1, 1)
    def puntos_silla(m):
    if not m or not m[0]:                       # guardián
        return []
    filas, cols = len(m), len(m[0])

    # Paso 1: mínimo de cada fila
    min_filas = []
    for i in range(filas):
        minimo = m[i][0]
        for j in range(1, cols):
            if m[i][j] < minimo:
                minimo = m[i][j]
        min_filas.append(minimo)

    # Paso 2: máximo de cada columna (bucles invertidos)
    max_cols = []
    for j in range(cols):
        maximo = m[0][j]
        for i in range(1, filas):
            if m[i][j] > maximo:
                maximo = m[i][j]
        max_cols.append(maximo)

    print("[DEBUG] min_filas:", min_filas, "max_cols:", max_cols)

    # Paso 3: celdas que cumplen ambas condiciones
    sillas = []
    for i in range(filas):
        for j in range(cols):
            if m[i][j] == min_filas[i] and m[i][j] == max_cols[j]:
                sillas.append((i, j, m[i][j]))
    return sillas

m1 = [
    [9, 1, 8],
    [11, 7, 10],
    [4, 2, 6],
]
m2 = [
    [1, 2],
    [3, 0],
]
print(puntos_silla(m1))    # [(1, 1, 7)]
print(puntos_silla(m2))    # []
